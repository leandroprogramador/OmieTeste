# Omie - Processo Seletivo

Este projeto foi criado como parte do processo seletivo para a vaga de **Desenvolvedor Android Sênior** na empresa **Omie**.

## 📌 Requisitos do Projeto
Criar um aplicativo onde o usuário possa:
- Adicionar pedidos com produtos.
- Consultar os pedidos posteriormente.
- Armazenar todos os dados localmente.

## 🚀 Tecnologias e Ferramentas Utilizadas

- **Linguagem**: Kotlin
- **Arquitetura**: MVVM
- **Injeção de Dependências**: Dagger Hilt
- **Banco de Dados Local**: Room ORM
- **Testes**: Testes unitários na classe DAO

## 📂 Estrutura do Projeto
O projeto segue a arquitetura **MVVM**, separando as camadas de **UI, ViewModel e Repository**, garantindo melhor organização e manutenibilidade.

## Instalação
É possível acessar a apk em modo debug na raiz do projeto
